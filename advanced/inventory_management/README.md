# 📦 Inventory Management System (Java)

## 📌 Description

A console-based inventory management system demonstrating the use of Java Collections and Streams API.

---

## 🚀 Features

* View all products in the inventory,
* Add a new product,
* Remove a product by ID,
* Filter and view low stock products using Java Streams,
* Pre-populated sample data.

---

## 💡 Concepts Used

* Java Collections (Lists)
* Java Streams API
* Lambda Expressions
* Object-Oriented Programming

---

## ▶️ How to Run

```bash
javac advanced/inventory_management/*.java
java inventory_management.Main
```
