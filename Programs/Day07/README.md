# 📅 Day 07 – Advanced Java Concepts & Algorithms

This day focuses on demonstrating advanced Java capabilities, concurrency, modern features, and essential data structures and algorithms.

---

## 🚀 Overview

Day 07 explores high-level Java features and algorithmic logic. 
It includes a mix of:

* Graph Theory and Trees
* Dynamic Programming
* Advanced Concurrency and Thread Pooling
* Modern Java APIs (NIO, Optional, Annotations)
* Reflection and Networking

---

## 🧠 Topics Covered

### 🌳 Data Structures & Algorithms

* Binary Search Tree (Insertion and Inorder Traversal)
* Graph Traversal using Breadth-First Search (BFS)
* Dynamic Programming with the 0-1 Knapsack Problem

### ⚙️ Multithreading & Concurrency

* Implementing Thread Pools using `ExecutorService`
* Asynchronous Programming with `CompletableFuture`

### 🛠️ Modern Java Features & Metaprogramming

* Non-Blocking I/O (NIO) for reading and writing files
* Understanding `java.util.Optional` to handle nulls gracefully
* Using the Reflection API to inspect classes dynamically
* Creating and consuming Custom Annotations
* Basics of Networking with Socket Programming
